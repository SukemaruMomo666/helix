Buku Panduan Singkat Helix

Panduan penggunaan platform https://thelix.shop untuk Customer, Seller, dan Admin.

🛍️ Panduan Pembeli (Customer)

1. Registrasi & Login

Buka thelix.shop, klik menu Masuk / Daftar di pojok kanan atas. Buat akun baru sebagai pembeli, lalu login dengan email dan password Anda.

2. Mencari Produk

Gunakan kolom pencarian di beranda untuk mencari material yang dibutuhkan, atau jelajahi menu Kategori. Klik pada gambar produk untuk melihat detail dan harga.

3. Masukkan ke Keranjang

Pada halaman produk, tentukan jumlah barang yang ingin dibeli, lalu klik tombol Masukkan Keranjang.

4. Proses Checkout

Buka menu Keranjang di kanan atas, centang barang yang ingin dibeli, lalu klik Checkout. Isi alamat pengiriman, pilih kurir (opsi Grab Sameday/Instant tersedia), lalu selesaikan pesanan.

5. Pembayaran (QRIS / Midtrans)

Di halaman terakhir, scan QRIS yang muncul menggunakan DANA/GoPay/MBanking (Nominal akan otomatis terisi), atau bayar lewat Midtrans. Lalu klik Konfirmasi WA untuk memberitahu Admin.

🏪 Panduan Penjual (Seller)

1. Membuka Toko

Buka thelix.shop/buka-toko. Isi nama toko, alamat, dan data diri Anda. Setelah disetujui, Anda akan masuk ke Dashboard Seller.

2. Login ke Seller Centre

Kunjungi seller.thelix.shop (atau akses via menu web), masukkan kredensial toko Anda untuk mengelola toko.

3. Mengatur Profil & Titik Jemput (GPS)

Penting! Masuk ke menu Pengaturan Toko, pastikan Anda menyematkan *Pin Lokasi Google Maps* agar sistem ongkir Biteship bisa berfungsi menghitung jarak ke pembeli.

4. Menambah Produk

Buka menu Produk Saya, klik tombol Tambah Produk. Masukkan nama barang, foto produk (maks 8), kategori, harga, dan berat barang (dalam gram). Lalu klik Simpan.

🛡️ Panduan Admin

1. Akses Halaman Login Admin

Kunjungi jalur khusus admin di thelix.shop/admin.

2. Login Panel

Masukkan email dan password Administrator. Pastikan kredensial ini sangat dirahasiakan.

3. Mengatur Sistem

Setelah login, Admin dapat masuk ke menu Pengaturan untuk mengganti logo, mengatur mode pembayaran (QRIS/Midtrans), API Kurir, dan mengelola toko mitra.
